# КЛИК | Медиа-маркет — v9

Добавлено фото профиля для блогеров и контент-креаторов.

- фото запрашивается сразу после имени;
- сохраняется Telegram `file_id` в PostgreSQL;
- новые деплои фото не стирают;
- при повторном редактировании профиля фото можно заменить;
- фото показывается в карточке профиля, медиа-базе и при новом отклике бизнесу;
- старые профили без фото продолжают работать;
- остальная логика v8 не менялась.

Railway Variables без изменений:
BOT_TOKEN
ADMIN_ID
DATABASE_URL

## v12 — режим бизнеса для владельца
- В «👤 Режим пользователя» теперь три варианта:
  - Я блогер
  - Я контент-креатор
  - Я бизнес
- В режиме бизнеса владелец видит обычное меню бизнеса.
- Если профиля бизнеса ещё нет, бот предлагает создать его один раз.
- После создания профиля можно нажать «Создать заявку» и пройти новую анкету v11.
- В бизнес-режиме есть кнопка «Вернуться в панель владельца».
- Права ADMIN_ID не меняются.

## v15 — «Творцы» в пользовательском интерфейсе
Общее пользовательское название для блогеров и контент-креаторов — «Творцы».

Изменены только видимые пользователю тексты и названия разделов:
- «Медиа-база» / «База креаторов» → «Творцы»
- «Отклики креаторов» → «Отклики творцов»
- общие упоминания базы → «база творцов»

Роли «Блогер» и «Контент-креатор» остаются отдельными.
Технические названия, creator_type, creator_needed и структура PostgreSQL не менялись.


## v16 — модерация регистраций
В «🛡 Модерация» добавлены три отдельные очереди:
- Заявки бизнесов
- Заявки блогеров
- Заявки контент-креаторов

Каждая анкета открывается по одной.
Кнопки:
- ✅ Принять
- ❌ Отклонить

После решения автоматически показывается следующая анкета из той же очереди.

Показывается счётчик:
«Осталось: N».

Новые регистрации получают статус pending.
После одобрения — active.
После отклонения — rejected.

Пользователь получает уведомление о результате модерации.
